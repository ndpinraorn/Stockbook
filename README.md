# สมุดพอร์ตหุ้น

จดราคาซื้อขายหุ้นไทยและหุ้นสหรัฐ ดูกำไร ROI และปันผลเป็นเงินบาท อ่านภาพคำสั่งจาก Dime ได้ เข้าสู่ระบบด้วยชื่อผู้ใช้กับ PIN แล้วเห็นข้อมูลเดียวกันทุกเครื่อง

## ไฟล์ในโปรเจกต์
- `index.html` หน้าเว็บทั้งหมด
- `parse.js` ตัวแปลงข้อความจากภาพ Dime เป็นราคา จำนวนหุ้น เรต และวันที่
- `api/auth.js` สร้างบัญชี / เข้าสู่ระบบ / ออกจากระบบ (PIN เก็บแบบเข้ารหัส scrypt)
- `api/data.js` อ่านและบันทึกข้อมูลของแต่ละบัญชี
- `api/dividends.js` ดึงประวัติปันผลจาก Yahoo Finance (ฟรี ไม่ต้องใช้ key)
- `api/_lib.js` ตัวช่วยที่ใช้ร่วมกัน (เชื่อม Upstash Redis ผ่าน REST ไม่ต้องลงแพ็กเกจ)

## ขึ้น Vercel (ทำผ่านเว็บทั้งหมด)
1. สมัคร github.com แล้วกด New repository ตั้งชื่อ เช่น `stockbook` แล้วกด Create
2. ในหน้า repo กด "uploading an existing file" ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `api`) ไปวาง แล้วกด Commit changes
3. สมัคร vercel.com ด้วยบัญชี GitHub แล้วกด Add New → Project เลือก repo `stockbook` แล้วกด Deploy
4. เชื่อมฐานข้อมูลสำหรับระบบล็อกอิน: ในหน้าโปรเจกต์บน Vercel ไปที่แท็บ **Storage** → เลือก **Upstash** (Redis) → Create → เลือกแผน Free → Connect กับโปรเจกต์นี้
5. ไปที่แท็บ **Deployments** กดจุดสามจุดของรายการบนสุด → **Redeploy** เพื่อให้เว็บเห็นฐานข้อมูล
6. เปิดเว็บ กด "สร้างบัญชี" ตั้งชื่อผู้ใช้กับ PIN แล้วใช้ชื่อกับ PIN เดิมเข้าจากเครื่องอื่นได้เลย

ถ้ายังไม่ทำข้อ 4–5 เว็บยังใช้ได้ กด "ใช้แบบไม่ล็อกอิน" ข้อมูลจะเก็บในเครื่องนั้น และย้ายเข้าบัญชีทีหลังได้ด้วยปุ่ม "ย้ายเข้าบัญชี"

## ข้อควรรู้
- ระบบล็อกอินเป็นแบบง่าย ใส่ PIN ผิด 8 ครั้งบัญชีจะถูกล็อก 15 นาที ลืม PIN ยังกู้คืนเองไม่ได้ ตั้ง PIN ที่จำได้ และกดดาวน์โหลดไฟล์สำรองไว้เป็นระยะ
- ทุกการแก้ไขบันทึกเป็นรายการ ๆ ไป ถ้าแก้จากสองเครื่องพร้อมกันจะไม่ทับกันทั้งสมุด ถ้าออฟไลน์ ระบบเก็บรายการไว้แล้วส่งให้เมื่อกลับมาออนไลน์
- ครั้งแรกที่อ่านภาพจะโหลดตัวอ่านภาษาไทยก่อน ภาพไม่ถูกส่งออกจากเครื่อง
- ปันผลแบบ "ประมาณ" หักภาษี 15% (หุ้นสหรัฐ) และ 10% (หุ้นไทย) กด "ใส่ยอดจริง" เพื่อใส่ตัวเลขจาก Dime
